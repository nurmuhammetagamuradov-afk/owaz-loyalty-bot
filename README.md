# Owaz Coffee — бот карты лояльности

Telegram-бот виртуальной карты лояльности для кофейни Owaz.

## Как работает
- Гость запускает бота и получает карту с QR-кодом
- Кассир сканирует QR камерой телефона и начисляет визит
- Уровень и скидка растут автоматически

## Уровни
| Уровень | Визиты | Скидка |
|---|---|---|
| MYHMAN | 1–9 | — |
| OWAZ DOSTY | 10–29 | 5% |
| HEMIŞELIK MYHMAN | 30–59 | 10% |
| ZAWSEGDATAÝ | 60–99 | 15% |
| VIP OWAZ | 100+ | 20% |

## Переменные окружения
- `BOT_TOKEN` — токен от @BotFather
- `BOT_USERNAME` — Owaz_Coffee_Bot
- `ADMIN_ID` — Telegram ID владельца
- `CAFE_NAME` — OWAZ
- `DB_DIR` — /data (папка постоянного диска)
